# Brand Package (Name + Logo + Social + Content + Guidelines)

## Asset Identity

| Field | Value |
|---|---|
| Asset type | Pre-built brand bundle: name + logo + social handles + content library + brand guidelines (no operating revenue yet, OR small pre-revenue) |
| Primary platform | **VibeFlippers** |
| Cross-listable to FW? | No (digital-only at this asset stage) |
| Typical price range | $500–$50K (pre-revenue) |
| Typical valuation | Component sum: domain value + handle availability + design value + content library + audience-builder |
| EF equivalent | NOT in EF catalog — they require revenue. This is our Flippa/Sedo-meets-99designs play |
| Min listing threshold | None (any complete bundle) |
| Operator interview required? | ≥$5K listing |
| Make scenario | Brand-in-a-Box Fulfillment (#8) — 3 tiers (Basic / Pro / Premier) |

## What's typically included

- Brand name (verified availability)
- Domain (.com or top TLD)
- Matching social handles (IG, X, TikTok, YouTube, FB) — claimed and held
- Logo files (vector + raster + variations)
- Brand guidelines doc (colors, typography, voice, do/don't)
- Photography pack (stock licenses or custom)
- Content library (10–50 pre-written posts/articles/scripts)
- Pre-built landing page or simple site
- Email template designs
- Trademark search results (often not filed; flagged as buyer's option)
- Any pre-revenue traction (waitlist signups, beta users)

## What's typically excluded

- Trademark filing (separate USPTO/EUIPO filing — buyer's option)
- Operating accounts (no Stripe etc. since pre-revenue)
- Legal entity (buyer registers their own)

## Brand-package-specific gotchas

| Gotcha | Mitigation |
|---|---|
| **TM conflict discovered post-close** | Pre-close TM search; APA disclosure |
| **Social handle reclaimed by platform** (e.g. inactive policy) | Activity check at handover; quick first post |
| **AI-generated assets without commercial rights** | Force disclosure; buyer accepts in writing if AI-only |
| **Photography licenses non-transferable** | Identify in DD; buyer secures own license if needed |
| **Stock font licenses** | Disclose; commercial use may require purchase |
| **Domain in non-premium TLD** | Disclose all annual renewal premiums |
| **Brand similar to existing trademarked brand** | TM cease-and-desist risk; disclose |
| **Waitlist count inflated with bots/duplicates** | Email validation in DD |
| **Content reused from other clients** | Originality verification mandatory |

## Operator checks
- TM scan (USPTO + EUIPO + WIPO)
- Wayback + blacklist on domain
- Social handle ownership challenge (each platform)
- Plagiarism scan on content library
- Photography rights confirmation
