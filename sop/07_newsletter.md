# Newsletter

## Asset Identity

| Field | Value |
|---|---|
| Asset type | Email newsletter (paid Substack/beehiiv/Ghost or free with sponsor revenue) |
| Primary platform | **VibeFlippers** |
| Cross-listable to FW? | No |
| Typical price range | $5K–$2M+ |
| Typical multiple | 24–40x monthly net (paid subs); 18–30x monthly net (sponsor-driven) |
| EF equivalent | Hybrid of Content + Subscription category |
| Min listing threshold | $500/mo (paid) or 5K subs (free with sponsor record) |
| Operator interview required? | ≥$5K listing |

## What's typically included

- Newsletter platform account (Substack / beehiiv / Ghost / ConvertKit / Mailchimp)
- Subscriber list with engagement history
- Domain (often newsletter-name.com)
- All published archives
- Sponsor relationships + media kit
- Brand assets (logo, designs, voice doc)
- Operating SOPs (publish cadence, editorial calendar)
- Stripe / payment processor for paid subs
- Social handles (often included)

## What's typically excluded

- Founder's authored voice (unless transition writing contracted)
- Personal subscriber notes/relationships in DMs

## Newsletter-specific gotchas

| Gotcha | Mitigation |
|---|---|
| **Substack non-transferable in some cases** | Verify Substack ToS; some accounts require new account + list import |
| **Founder voice is the moat** | Earnout strongly recommended; soft pivot only after 90 days |
| **Paid sub Stripe non-transferability** | Migrate via Stripe Connect; subscribers may need to re-auth |
| **Subscriber lists with old opt-in** | Compliance check — re-permission campaign may be needed |
| **Sponsor exclusivity contracts** | Disclose; assignment clause review |
| **Deliverability tied to seller IP/domain reputation** | New SPF/DKIM/DMARC setup at cutover |
| **Cold-email-acquired list** | Disclose; may need full re-permission |
| **AI-generated content concerns** | Disclose AI % |
| **List portability (raw export availability)** | Confirm seller can produce CSV with all fields |

## Operator checks
- Bank ↔ Stripe ↔ platform revenue reconciliation
- Spam complaint rate (<0.1%)
- Re-permission status (CAN-SPAM/GDPR)
- Sample 20 random subscribers via Kickbox for deliverability
- Sponsor reference calls
