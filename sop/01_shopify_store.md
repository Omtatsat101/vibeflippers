# Shopify E-commerce Store

## Asset Identity

| Field | Value |
|---|---|
| Asset type | Shopify e-commerce store |
| Primary platform | **VibeFlippers** (digital-first) |
| Cross-listable to FW? | **Yes if** the store has a warehouse, leased fulfillment space, or owned inventory >$10K |
| Typical price range | $5K–$500K+ |
| Typical multiple | 28–35x trailing 6-month net profit (lower for unproven, higher for established + branded) |
| EF equivalent | EF E-commerce category |
| Min listing threshold | $1K/mo trailing 6-month net (Standard tier); $5K/mo for Growth tier |
| Operator interview required? | Yes for all listings ≥$10K |
| Empire Flippers benchmark | 28x–32x typical; 40x+ for premium brands with strong organics |

## What's typically included

- Shopify store ownership (Partner-managed transfer or full ownership transfer)
- Domain(s) (primary + redirects)
- Theme + custom code (if any)
- Product catalog (SKUs, descriptions, photography, variants)
- Customer database export (orders, emails, addresses, lifetime value)
- Email marketing list (Klaviyo / Mailchimp / Omnisend)
- Inventory (separately valued — not in multiple)
- Supplier contracts (POD providers, manufacturers, dropship suppliers)
- Brand assets (logo files, brand guidelines, photography rights)
- Operating SOPs
- Social media accounts (if part of brand — negotiated separately)
- Ad accounts (Meta, Google, TikTok — see asset 11)
- Analytics history (GA, Shopify Analytics, Triple Whale, etc.)

## What's typically excluded

- Founder's personal time beyond transition period
- Outstanding debt or accounts payable (unless explicitly assumed)
- Personal Shopify account email (transfer to new ownership account)
- Unrelated trademarks held by founder
- Pre-existing legal disputes

## Shopify-specific gotchas the platform must handle

| Gotcha | Mitigation |
|---|---|
| **Shopify Plus vs. Basic plan** | Listing must declare plan; Plus contracts often non-transferable — handled in APA |
| **Custom apps from Shopify App Store** | Buyer may need to re-subscribe; list every app + monthly cost in data room |
| **Custom code/themes** | Repo transfer required; code review by buyer's dev SP recommended |
| **Subscription customers** | Recharge / Bold subscriptions transfer separately — list active subscriptions, MRR |
| **Tax registration** (Shopify Tax / Avalara) | Buyer must re-register sales tax in their jurisdiction; surface in Stage 6 |
| **GDPR / CCPA** | Customer data transfer requires lawful basis statement in APA |
| **Trademark transfer** | Separate USPTO/EUIPO assignment outside escrow; flagged in APA |
| **Outstanding ad balances** (e.g., negative Meta balance) | Net out of purchase price OR seller settles before close |
| **Pixel / tracking history** (Meta/TikTok) | Audiences belong to ad account → transferred with BM access |
| **Negative reviews / ToS strikes** | Disclose during Stage 2; affects Verification Score |
