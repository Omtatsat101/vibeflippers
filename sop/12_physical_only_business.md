# Physical-Only Business (Laundromat / Gym / Salon / Restaurant / Auto Shop / etc.)

## Asset Identity

| Field | Value |
|---|---|
| Asset type | Brick-and-mortar service business with minimal/no online operating component |
| Primary platform | **FlipWala** |
| Cross-listable to VF? | No |
| Typical price range | $20K–$5M+ |
| Typical multiple | 2–3.5x SDE (Seller's Discretionary Earnings); higher for branded chains |
| EF equivalent | NOT in EF catalog (they're digital-only) |
| BizBuySell / BizQuest equivalent | This is their core market |
| Min listing threshold | $30K/yr SDE |
| Operator interview required? | Always |
| Real-estate involvement | Triggers REQ-008 jurisdiction routing |
| Licensed broker required? | Per state — flagged at Stage 1 |

## What's typically included

- Operating business (lease assignment OR owned property in separate transaction)
- All equipment (washers/dryers, salon chairs, gym machines, kitchen, etc.)
- Inventory at agreed valuation
- Customer relationships / regulars / membership database
- Employees (W-2 or 1099 — separate transition agreements)
- Vendor relationships (suppliers, maintenance, utilities, services)
- Local business license + permits
- Sales tax registration
- Phone number (often valuable for established locals)
- Signage + branding rights
- Workers' comp + general liability insurance setup (must rebind under buyer)
- Point of sale (POS) account access
- Any digital presence (Google My Business, Yelp, Facebook page) — small but transferable

## What's typically excluded

- Real property (usually a separate RE transaction if owned)
- Personal vehicles
- Outstanding payroll/tax obligations
- Pre-existing employee disputes (EEOC, wage claims)
- Owner's personal customer relationships not tied to business

## Physical-only-business gotchas

| Gotcha | Mitigation |
|---|---|
| **Landlord refuses lease assignment** | Pre-engage landlord at Stage 1; deal-killer if they refuse |
| **Personal guarantee on lease** | New lease with buyer's PG; old released |
| **Inventory shrinkage** | Inventory adjustment clause |
| **Employee resignations after announcement** | Stay bonuses; retention hold-back |
| **Sales tax exposure** (uncollected) | Indemnification + escrow hold-back |
| **WARN Act / mass layoff** | Comply with notice timing |
| **Equipment liens (UCC)** | Force payoff at close from escrow |
| **Workers' comp claims tail** | Seller policy stays open for tail |
| **Environmental contamination** | Phase 1 ESA mandatory for industrial/auto |
| **Local business license non-transferability** | Buyer registers own license |
| **Health code violations history** | Disclose; affects price |
| **Zoning compliance** | Buyer confirms current use compliant |
| **Lease term remaining < 5 years** | Risk factored into multiple |
| **Customer churn from new ownership** | Soft launch; loyalty incentives |
| **Phone number tied to seller's contract** | Port to buyer's account |
| **GMB ownership transfer** | Use Google's transfer flow before signage changes |

## Operator checks (physical)
- On-site walkthrough + photo/video evidence
- Equipment condition + life-remaining estimate
- Lease assignability confirmation
- Health/safety inspection history (where relevant)
- Bank reconciliation against POS
- UCC + title searches
