# Hybrid E-commerce + Warehouse / Lease

## Asset Identity

| Field | Value |
|---|---|
| Asset type | E-commerce store with attached physical operations: warehouse, leased fulfillment space, owned inventory >$10K, employees |
| Primary platform | **FlipWala** (because of physical-first nature) |
| Cross-listed to VF? | **Yes — always.** Digital components (store, brand, social) cross-list to VF |
| Typical price range | $25K–$2M+ |
| Typical multiple | 2–4x SDE (Seller's Discretionary Earnings) — physical-business standard, not e-comm multiple |
| EF equivalent | Bridges EF (FBA) and BizBuySell (physical biz) — neither covers this cleanly |
| Min listing threshold | $5K/mo trailing 12-month SDE |
| Operator interview required? | Always (mandatory on-site or video tour) |
| Real-estate involvement | Triggers jurisdiction compliance routing (REQ-008) |

## What's typically included

- Everything from asset 01 (Shopify Store) — see [01_shopify_store.md](01_shopify_store.md)
- **Plus:**
  - Lease agreement(s) — assignment or new lease negotiation
  - Equipment (forklifts, racking, packing stations, shipping equipment)
  - Inventory at cost or negotiated valuation
  - Employees (W-2 or contractor — separate transition agreements)
  - Workers' comp + general liability insurance setup
  - Local business license + sales tax registration
  - 3PL contracts (if hybrid 3PL + own warehouse)
  - Vehicle assets (delivery vans, etc.)

## What's typically excluded

- The real property itself (if owned, not leased — that's a separate real-estate transaction)
- Outstanding payroll obligations
- Pre-existing employee disputes / EEOC matters
- Owner's personal vehicles

## Hybrid-specific gotchas

| Gotcha | Mitigation |
|---|---|
| **Landlord refuses lease assignment** | Pre-engage landlord during Stage 1; deal-killer if they refuse |
| **Personal guarantee on lease** | New lease with buyer's PG; old PG released by landlord |
| **Inventory shrinkage between count and close** | Inventory adjustment clause in APA |
| **Employee resignations after announcement** | Stay bonuses; hold-back of part of purchase price tied to retention |
| **Sales tax exposure** — if seller didn't collect properly | Indemnification clause + escrow hold-back |
| **WARN Act / mass layoff** | If layoffs planned, comply with notice rules; bake into close timing |
| **Equipment liens (UCC)** | Force payoff at close from escrow proceeds |
| **Workers' comp claims tail** | Seller's policy stays open for tail period; covered in APA |
| **Environmental contamination** | Phase 1 ESA mandatory for industrial; Phase 2 if Phase 1 flags issues |
| **Local business license non-transferability** | Buyer registers their own; coordinate timing |
| **Local zoning compliance change** | Buyer confirms current use is compliant; flagged in DD |
| **Customer churn from change of ownership** | Soft-launch new ownership; loyalty incentives |
