# Content Website / Blog

## Asset Identity

| Field | Value |
|---|---|
| Asset type | Content site, niche blog, affiliate site, AdSense site |
| Primary platform | **VibeFlippers** |
| Cross-listable to FW? | No |
| Typical price range | $1K–$500K |
| Typical multiple | 30–45x trailing 6-month net profit |
| EF equivalent | EF Content category — their bread and butter |
| Motion Invest equivalent | Their primary asset class |
| Min listing threshold | $500/mo (Self-Serve); $1K/mo (Standard); $5K/mo (Growth) |
| Operator interview required? | Yes ≥$5K listing |

## What's typically included

- Domain
- All content (articles, images, videos)
- WordPress / CMS setup + database
- Hosting account or migration plan
- AdSense / Mediavine / Ezoic / monetization account or migration
- Affiliate accounts (Amazon, ShareASale, etc.) — usually migrate vs. transfer
- Email list
- Social media accounts (negotiated separately)
- SEO assets: backlink profile, GSC data, GA history
- Brand assets

## What's typically excluded

- Founder's writing services (unless contracted)
- Personal AdSense account (must migrate to buyer's account)
- Unrelated sites in same hosting account (split required)
- Author bio content tied to founder identity (can be edited post-close)

## Content-site-specific gotchas

| Gotcha | Mitigation |
|---|---|
| **Mediavine / Ezoic non-transferability** | Verify ad partner TOS allows transfer OR plan for buyer to apply fresh |
| **AdSense site re-approval** | Site stays under seller's account during 30-day transition; switch over once buyer-approved |
| **Amazon Associates non-transferability** | Buyer sets up own; sed-replace links during cutover |
| **Hosting tied to seller's email** | Always migrate to buyer's host before cutover |
| **Domain locked at registrar** | Auth code released only at escrow funding |
| **Content quality drift** | Sample audit of 20 random articles in DD |
| **Plagiarism / spun content** | Full Copyscape pass during DD |
| **AI content + future Google updates** | Buyer accepts risk in writing in APA |
| **Backlink penalties** | Ahrefs toxic ratio scan + manual action log review |
| **Wayback Machine deindexing history** | Check; flag if site has been deindexed previously |
| **Plugin / theme licensing** | Premium licenses must transfer or buyer purchases own |
