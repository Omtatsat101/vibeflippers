# Franchise (with optional digital layer)

## Asset Identity

| Field | Value |
|---|---|
| Asset type | Existing franchise location (or multi-unit territory) of a national/regional brand |
| Primary platform | **FlipWala** |
| Cross-listable to VF? | Yes if franchise has digital ordering/loyalty/branded mobile app component |
| Typical price range | $50K–$10M+ |
| Typical multiple | 2–4x SDE; varies by brand strength + remaining franchise term |
| EF equivalent | NOT in EF catalog |
| BizBuySell equivalent | Yes — one of their core categories |
| Min listing threshold | $50K SDE |
| Operator interview required? | Always |
| Franchisor approval | **Required** — non-negotiable gate |

## What's typically included

- Franchise rights for the territory (must be transferred via franchisor)
- Equipment + tenant improvements
- Inventory at agreed valuation
- Lease assignment OR new lease
- Employees (per separate transition agreements)
- Customer relationships / loyalty database
- Local marketing assets
- POS access + franchisor systems access
- Local social media accounts
- Local Google My Business listing
- Phone number

## What's typically excluded

- Franchisor-owned IP (logo, recipes, manuals, training)
- Personal customer relationships
- Outstanding franchise fee obligations
- Pre-existing franchisor disputes

## Franchise-specific gotchas

| Gotcha | Mitigation |
|---|---|
| **Franchisor refuses approval** | Deal collapses; LOI exclusivity returns time to seller |
| **Franchisor exercises ROFR** | Deal pivots to franchisor as buyer at same terms; buyer paid for DD wasted |
| **Required remodel coming under FA** | Disclose; may require buyer's capital expenditure |
| **Royalty rate increases at renewal** | Disclose in FDD review |
| **Tech fees / mandatory POS** | Disclose ongoing tech load |
| **Franchisor planned changes** (rebrand, new operating model) | FDD review surfaces |
| **Co-tenancy / non-compete** in lease | Lease review |
| **Local territory encroachment risk** | Territory rights review |
| **Transfer fee** (often $5K–$50K) | Pay from escrow at close |
| **Franchisor requires buyer to attend training** | Plan timeline; franchisee can't operate until trained |
| **Existing franchisor disputes / cure notices** | Mandatory disclosure |
| **Franchisor has the right to require system upgrades mid-FA-term** | Disclose; budget |

## Operator checks
- Franchisor approval timeline + likelihood
- FDD currency (last 12 months)
- ROFR status
- Other franchisees' satisfaction (Item 20 references)
- All physical asset 12 checks

## Real-world consideration

Franchisor approval is the longest gate in any FW deal. Plan 30–60 day approval window AFTER LOI. Some buyers walk during this period. Earnest money (refundable) is unusual but increasingly common to keep buyers committed.
