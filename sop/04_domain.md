# Premium / Aged Domain

## Asset Identity

| Field | Value |
|---|---|
| Asset type | Standalone domain (no site, or with parking page) |
| Primary platform | **VibeFlippers** |
| Cross-listable to FW? | No |
| Typical price range | $50–$500K+ (rare million-dollar exits) |
| Typical valuation | Sedo / EstiBot estimate + 5–10% verification premium |
| EF equivalent | Domains are NOT in EF's catalog — they don't sell standalone domains |
| Sedo / GoDaddy Auctions / Afternic equivalent | Yes — these are the volume comparables |
| Min listing threshold | None (any registered domain) |
| Operator interview required? | Only for listings ≥$10K or aged ≥10 years |

## What's typically included

- Domain only (transferred via auth/EPP code)
- Optionally: matching social handles
- Optionally: matching email addresses (less common)
- Optionally: parking page traffic + revenue history

## What's typically excluded

- Hosting (no site)
- Trademarks (separate USPTO/EUIPO transfer)
- Email forwarding (must be re-set up)

## Domain-specific gotchas

| Gotcha | Mitigation |
|---|---|
| **60-day ICANN lock after registration / prior transfer** | Verify domain isn't locked at Stage 1; otherwise wait |
| **Registrar requires their own escrow/marketplace** | Use registrar's transfer service OR migrate domain first |
| **Trademark dispute risk (UDRP)** | Buyer accepts in APA; mandatory TM disclosure by seller |
| **Premium-tier registry domains** (e.g. .io, .ai, .co with renewal premiums) | Disclose annual renewal cost |
| **Domain associated with prior abuse** | Wayback + blacklist scan mandatory |
| **DNS pointing during transfer** | Coordinate cutover; old DNS may still resolve for 24–48 hours |
| **WHOIS privacy + verification** | Some registrars flag the listing; coordinate ahead |
| **Transfer fee at receiving registrar** | Buyer pays; typically $8–$15 |
| **Failed auth code** | If ICANN transfer fails, escrow returns funds; APA retry clause |
| **High-value domains (>$50K) often need bank escrow** | Use Escrow.com Premier tier or bank escrow |
