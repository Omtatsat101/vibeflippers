| Field | Value |

| Min listing threshold | _e.g. $1K/mo trailing 6-month_ |
| Operator interview required? | Yes / No / >$X only |

## What's typically included

- _Domain(s)_
- _Hosting / infrastructure access_
- _Data exports (customers, orders, inventory)_
- _Brand assets (logo, content, photography)_
- _Operating SOPs_
- _Supplier/vendor contracts_
- _Email list / marketing automation_
- _Social accounts (if any)_
- _Ad accounts (if any)_

## What's typically excluded (require negotiation)

- _Founder time post-close_
- _Personal email/Slack access_
- _Personal financial accounts_
- _Trademark transfer (separate filing)_
- _Outstanding debt_

## Operator-side checkpoints (per stage)

| Stage | Operator action |
|---|---|
| 1 | Confirm seller passes minimum threshold; assign deal |
| 2 | Validate analytics data; cross-reference revenue claims; issue Verification Score |
| 3 | Approve listing copy + pricing; publish |
| 4 | Monitor reveal patterns for unusual activity |
| 5 | Witness LOI signing; trigger exclusivity timer |
| 6 | Stay neutral in deal room; escalate ghosting; flag deal-killer findings |
| 7 | Verify each handover step; confirm escrow funding; trigger funds release on inspection sign-off |
| 8 | Submit closing report to Admin; flag any disputes |

## Settlement

| Trigger | Action |
|---|---|
| Buyer signs LOI | (no payment yet — exclusivity only) |
| Buyer signs APA + funds escrow | Escrow.com holds funds |
| Both parties confirm handover complete | Inspection period starts (3–7 days) |
| Buyer signs off on inspection | Funds released to seller; commission split to platform via Stripe Connect |
| Earnout structure | Revenue continuity tracked monthly; held-back % released per APA |

## Required artifacts archived per deal

- Listing Agreement (seller signed)
- Verification Score report
- LOI
- APA
- Due diligence Q&A transcript
- Handover checklist (signed by both parties)
- Closing report
